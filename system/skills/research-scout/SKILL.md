# Research Scout — ежедневный разведчик

Этот skill превращает агента в ресёрчера, который каждый день патрулирует интернет по трём направлениям Антона и приносит только то, что стоит внимания.

---

## Что этот skill делает

1. Ищет свежие материалы по трём направлениям
2. Фильтрует: только релевантное и свежее
3. Создаёт структурированные карточки
4. Сохраняет в vault

## Три направления

Прочитай полное описание направлений в:
`/Users/anton/AI AGENT FOLDER/Second Brain/system/rules/{POS} {rule} research department architecture – 2026-04-09.md`

Кратко:
- **AI-native бизнес** — компании, агенты в бизнесе, экономика токенов
- **Креативная индустрия + AI** — реклама, продакшн, студии, контент
- **Vibecoding и инструменты** — модели, фреймворки, Personal OS, агентные паттерны

## Протокол работы

### Шаг 1: Поисковые запросы

Для каждого направления выполни 2-3 поисковых запроса. Чередуй русские и английские.

**AI-native бизнес:**
- "AI native company case study 2026"
- "AI agents business automation"
- "AI трансформация компании кейс"

**Креативная индустрия + AI:**
- "AI advertising production studio 2026"
- "AI video generation creative agency"
- "AI реклама продакшн студия"

**Vibecoding и инструменты:**
- "vibe coding tools framework 2026"
- "multi agent system personal OS"
- "Claude Code MCP agents new"

**Адаптация:** если Антон указал конкретную тему — добавь к стандартным запросам 2-3 запроса по его теме.

### Шаг 2: Фильтрация

Для каждого найденного результата проверь:

| Критерий | Проходит | Не проходит |
|----------|----------|-------------|
| Свежесть | Последние 7 дней | Старше недели |
| Глубина | Конкретный кейс, данные, методология | Общие слова, "AI изменит мир" |
| Релевантность | Связано с контекстом Антона | Чистая академия без практики |
| Уникальность | Новая идея или угол | Повтор известного |

**QA-правило:** если не можешь за 1 предложение объяснить, почему это важно для Антона — не сохраняй.

### Шаг 3: Чтение и карточка

Для каждого прошедшего фильтрацию результата:

1. Прочитай статью через WebFetch (если доступна)
2. Если статья недоступна — работай с тем, что дал поиск
3. Создай карточку по шаблону ниже

### Шаг 4: Сохранение

Сохрани каждую карточку в:
`/Users/anton/AI AGENT FOLDER/Second Brain/education/`

Имя файла:
```
{research} {scout} [краткая тема] – YYYY-MM-DD.md
```

Пример:
```
{research} {scout} Anthropic запустил MCP marketplace – 2026-04-09.md
```

### Шаг 5: Отчёт

После завершения выведи краткий отчёт:

```
Research Scout — [дата]
Найдено: X результатов
Сохранено: Y карточек
По направлениям: AI-native (N), Creative+AI (N), Vibecoding (N)

Топ-3 находки:
1. [название] — [почему важно]
2. ...
3. ...
```

## Режимы работы

### Режим: Полный патруль (scheduled / по запросу)
Триггер: "research scout", "патруль", "что нового"
Действие: все 5 шагов, все 3 направления.

### Режим: Тематический поиск
Триггер: "найди статьи про [тема]", "research [тема]"
Действие: шаги 1-5, но только по указанной теме. Запросы адаптируй под тему.

### Режим: Quick scan
Триггер: "быстрый скан", "что горячего"
Действие: по 1 запросу на направление, только топ-3 результата. Без карточек — просто список с TL;DR.
