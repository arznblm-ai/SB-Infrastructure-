# Глоссарий доменов — память /grill

> Ubiquitous language Антона. Одна строка на термин. Пополняется после грилинг-сессий; коллизии значений называются вслух. Держать ≤60 строк.

- **Хаб** — консалтинг-хаб Антон × Виталик (Консалтинг Creative Industry); не путать с «хабом» как техническим узлом.
- **Гермес** — агент разговорного менеджмента на VPS (фокус, календарь, задачи-видимость); чат с ним — просто «Гермес», отдельного имени у чата нет (поправка Антона 2026-08-08); внутри чата есть топики (встречи — 1260685).
- **Алина** — изолированный Docker-бот-продюсер дизайнеров; Гермес — пульт над ней, не она сама.
- **Конвейер** — model-pipeline: план (Sonnet) → архитектура (Fable) → исполнитель; «руки» — исполнитель, «мозг» — главная сессия.
- **Задачный бот** — telegram_codex_bot на VPS: /todo, /triage, голосовой чекин; не Гермес.
- **Копилка** — архив выпусков/знаний в vault для чтения агентами (пример: digests/ у AI Twitter Digest).
- **Ранбук** — детерминированный bash-скрипт в deploy/, который Антон запускает на VPS сам; агентам ssh-write к проду запрещён (ADR-013).
- **Секции Todoist** — 📥 Новое (intake) / 🔥 Эта неделя (лимит 10) / ⏳ Жду ответа / 🧊 Потом; дата = обязательство.
- **Область** — рабочая зона задачи в Todoist (7 area-labels), не проект Todoist.
- **UGC-завод** — контент-производство UGC/AIGC (клиентский трек), не путать с UGSEE (продукт).
- **Ноутс** — саммари встречи от Meeting Notes (в топик Гермеса); «бриф» — мёртвый жанр полного Daily Focus (выведен, ADR-011).
