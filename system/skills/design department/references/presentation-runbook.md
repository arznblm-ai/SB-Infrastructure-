# Presentation Runbook

Короткий runbook для новой stateless-системы агентов.

Этот файл проектно-нейтрален: его можно копировать в любой новый проект вместе со всей папкой `agents`.

## Роли

- `Presentation Designer` — дизайнерский агент для визуального направления и редизайна deck
- `Generator` — редактор активной версии deck
- `Critic` — строгий reviewer активной версии deck

## Главное правило

Оба агента работают только с файлами, явно переданными в текущем запуске.

Если активный deck не указан явно, запуск считается плохо подготовленным.

## Базовый цикл

1. Выбери активную версию deck.
2. Если нужен редизайн, сначала передай ее `Presentation Designer`.
3. Если нужны правки содержания или структуры, передай эту же версию `Generator`.
4. После правок передай эту же версию `Critic`.
5. Если нужно, повтори цикл.

## Что обязательно передавать

- активный deck HTML
- активный PDF
- папку текущих screen renders
- исходный прототип экранов, если их можно трогать
- export script, если нужен пересбор
- комментарии пользователя для этого раунда

## Что нельзя делать

- подсовывать агенту неявный “текущий deck”
- просить review по памяти
- смешивать текущую ревизию и старые версии в одном запуске без явной причины
- переносить старые замечания как обязательные, если пользователь уже сменил направление
