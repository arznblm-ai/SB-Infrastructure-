# Кобальт: дизайн-система Instagram-каруселей

### [[2026-11-13]]

**Атмосфера:** редакционная тетрадь на кремовой бумаге, где автор подчеркивает главное кобальтовой ручкой и желтым маркером.

Файлы: `base.css` (токены, шрифты, базовые классы), `fit.js` (подгон строк заголовка), `doodles/` (20 SVG, превью `doodles/index.html`), эталон `../examples/test-ai-remake/`.

## Палитра

| Токен | Hex | Роль |
|---|---|---|
| `--canvas` | `#faf9f5` | фон слайда (крем) |
| `--card` / `--cream` / `--hair` | `#efe9de` / `#e8e0d2` / `#e6dfd8` | светлые подложки, линейки |
| `--ink` | `#141413` | тушь: заголовки, цифры, штрих рисунков |
| `--body` | `#3d3d3a` | основной текст |
| `--muted` | `#6c6a64` | метки, счетчик |
| `--accent` | `#2340E3` | кобальт: курсив заголовка, карточки, кнопка, точка метки |
| `--tint` | `#D3DAFA` | бледная кобальтовая подложка, пятна под цифрами |
| `--pop` | `#F7C52D` | желтый: маркер, главное пятно, плашка-чип |

Кобальта на слайде одна крупная масса (карточка или курсив) и мелкие точки. Желтый только точечно: одно пятно или одно выделение.

## Типографика

- **Literata** 400 (курсив 400): заголовки, цифры, подписи-цитаты. `letter-spacing:-.025em`, `line-height:1.02`.
- **Golos Text** 400/500/600: текст, метки, кнопки.
- **JetBrains Mono** 400/500: промпты, ник, номера кадров.

| Элемент | Кегль |
|---|---|
| Обложка `h1` | 140–150 px (`data-fit="150"`) |
| Заголовок слайда `h2` | 110–124 px; CTA до 150 px |
| Подпись-цитата антиквой | 80–88 px |
| Цифры | 200 px, главная 280 px кобальтом |
| Лид `.lead` | 38 px / 1.35 |
| Текст `.txt`, промпт mono | 42 px |
| Метка `.tag`, счетчик | 26 px, метка капсом `.12em` |

Заголовок в две строки: первая тушью, **вторая курсивом кобальтом** (`<em class="l">`). Каждая строка в `<span class="l">`, контейнер с `data-fit="макс_px"`: `fit.js` подгоняет кегль под ширину.

## Сетка

- Холст 1080×1350 (4:5). Поля `--pad: 64px`, ничего значимого ближе 64 px к краю.
- Верх: строка `.top` на 60 px (клякса-метка слева, счетчик `NN/NN` справа), метка раздела `.tg` на 150 px.
- Обложка: сетка профиля показывает центр 3:4 (≈1012×1350, срезает по ~34 px слева и справа). Заголовок и смысл внутри этой зоны с запасом, у боковых краев только фон или кадр.
- Скругления: карточки 28 px, кадры в сетке 18–22 px, кнопка 16 px.

## Рисунки

- Одна шутка на слайд: один главный рисунок, максимум один мелкий спутник.
- Рисунок значит что-то в сюжете слайда, а не украшает: рамка = старая пленка, засечки = склейки, стрелка = «вот откуда», торнадо = «выбрал этот».
- Ставится поверх кадра или на стыке кадра и фона, слегка повернут (±4–12°). Не пиктограмма и не иконка.
- Цвета: штрих тушью или кобальтом (класс `c`), заливка `--doodle-fill` (желтый по умолчанию, `var(--tint)` для бледного), второй цвет `--doodle-accent`.

| Рисунок | Для чего |
|---|---|
| `underline-zap`, `zigzag-wave` | подчеркнуть слово заголовка (`stretch`) |
| `frame-wobble` | рамка вокруг кадра, «старое видео» (`stretch`) |
| `circle-tornado`, `scribble-tangle` | обвести выбранное |
| `arrow-worm` | указать от элемента к выводу |
| `action-burst`, `splat-burst`, `star-splat`, `sun-wonky` | удар, результат, «вау» |
| `blob-*` (bean, cloud, drop, pebble, puddle) | пятно под цифрой или словом |
| `rhythm-ticks`, `time-coil`, `spiral-wobble` | ритм, склейки, время, процесс |
| `bubble-wonky` + `asemic-line` | реплика, комментарий |

Вставка: `python3 scripts/doodle.py <name> --uid s041 --cls "ar"` или из Python `doodle(name, uid, color, fill, accent, width, rotate, cls)`. `uid` уникален на слайде (префикс id фильтров). Позиция и размер в `<style>` слайда по классу.

## Текст

- Без «ё», без длинных тире: запятые, двоеточия, простые слова.
- Строки ровные по длине, переносы руками через `<br>`; предлог и союз не в конце строки: `на&nbsp;6 кадров`, `за&nbsp;один вечер`.
- Основной текст не меньше 34 px, на обложке лид 38 px.
- Один слайд = одна мысль; жирным только первая фраза или ключ.

## Do / Don't

- **Do:** крем + тушь + кобальт, курсив кобальтом во второй строке, желтый как маркер, живые рисунки поверх кадров, ровный ритм полей 64 px.
- **Don't:** отсылки к Claude (коралл, звездочка-лучик, оранжевые акценты); AI-фиолетовые градиенты и неон; эмодзи; три одинаковые карточки в ряд; рисунок ради рисунка; больше двух рисунков на слайд; текст по краю ближе 64 px.

## Сборка карусели

```
python3 scripts/new_carousel.py "~/Desktop/Vibecode OUT/<дата>/carousel <тема>" 7   # заготовки + копия ds/
python3 scripts/render.py "<папка>"          # slides/*.html -> png/NN.png 1080x1350
python3 scripts/contact_sheet.py "<папка>"   # contact.png, лента для проверки
```
Карусель вне vault получает копию `base.css` и `fit.js` в `<папка>/ds/` (повторный запуск обновляет копию и не трогает готовые слайды). Шрифты грузятся из Google Fonts, нужна сеть.
