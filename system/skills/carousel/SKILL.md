# Carousel — карусели в системе «Кобальт»

### [[2026-11-13]]

План и решения грилинга: [[{self} {plan} агент каруселей грилинг – 2026-11-12]] (`tasks/Carousel/`). Тест дизайн-систем: `tasks/Carousel/ds-test/`. Содержательная стратегия формата — у Ники (`infrastructure/Nika/outputs/{self} {plan} методология форматов – 2026-11-09.md`, раздел «Карусель»).

## Что читать

1. `design-system/DESIGN.md` — палитра, шрифты, сетка, типы слайдов, рисунки, правила текста. Читать целиком перед вёрсткой.
2. `examples/test-ai-remake/slides/NN.html` — эталон нужного типа слайда (открывать только те типы, что нужны).
3. `design-system/doodles/index.html` / `--list` у `doodle.py` — имена рисунков.

## Вход

- **Тема** (агент пишет текст сам, Антон правит) или **готовый текст** Антона (агент только раскладывает и верстает, слова не меняет).
- **Картинки**: на старте Антон даёт свои кадры (файлы в сессию или папку). Генерации «в стиле Антона» пока нет. Картинок нет — спросить, не подставлять заглушки в финал.
- Если пришло от Ники — хук и тексты уже есть, берём их.

## Протокол

1. **Раскладка** (главная сессия): 5–10 слайдов, по умолчанию «как сделано»: хук-результат → кадры с подписями → промпты / шаги → цифры или вывод → CTA «сохрани». Таблица: № / тип слайда из DESIGN.md / картинка / текст дословно. Текст по правилам: без «ё», без длинных тире, запятые, простые слова, строки ровные, предлог не в конце строки. Если текст писал агент — показать таблицу Антону и дождаться «ок» до вёрстки.
2. **Папка**: `~/Desktop/Vibecode OUT/<YYYY-MM-DD>/carousel <тема>/` (новая версия = новая папка `… v2`, ничего не перезаписывать). Картинки Антона скопировать в `<папка>/assets/`.
   `python3 scripts/new_carousel.py "<папка>" <N>` — заготовки слайдов + копия `ds/`.
3. **Вёрстка** — исполнитель по `system/skills/route/SKILL.md` (дефолт реестра). Спецификация: путь к папке, таблица раскладки, пути к DESIGN.md и нужным эталонам, рисунки через `scripts/doodle.py` (одна шутка на слайд, смысловые), запреты (писать только в папку карусели, текст не менять, без git и отправок), проверка своими глазами (Read PNG). Композиции свободные в рамках системы, не копия эталона один в один.
4. **Рендер**: `python3 scripts/render.py "<папка>"` → `png/NN.png`; `python3 scripts/contact_sheet.py "<папка>"` → `contact.png`.
5. **Ревью** (главная сессия): Read `contact.png` + 1–2 крупных слайда. Чек-лист «Готово, если». Замечания списком исполнителю, максимум 2 итерации. HTML целиком не читать и не переписывать.
6. **Подпись**: `<папка>/caption.md` — подпись к посту (хук первой строкой, 2–5 коротких строк, CTA, по тем же правилам текста) + 3–5 хэштегов, если Антон их использует.
7. **Лог Ники**: строка в раздел «Лог роликов» `infrastructure/Nika/memory/{self} {research} память Ники – 2026-11-09.md`: дата | тема | карусель N слайдов | — | — | путь к папке. Метрики потом заполняет Ника по скрину.
8. Отправить Антону `contact.png` (SendUserFile) и путь к папке.

## Готово, если

- [ ] Все слайды 1080×1350, шрифты Literata / Golos Text / JetBrains Mono без фолбэка.
- [ ] Текст дословно по раскладке, без «ё» и длинных тире, без висячих предлогов, основной текст ≥34 px.
- [ ] Ничего значимого ближе 64 px к краю; обложка читается в центре 3:4.
- [ ] Одна крупная масса кобальта и максимум один желтый акцент на слайд; не больше двух рисунков на слайд, рисунки по смыслу.
- [ ] Никаких отсылок к Claude (коралл, звездочка), эмодзи, AI-градиентов.
- [ ] Есть `caption.md` и строка в логе Ники.
- [ ] Ничего не опубликовано.

## Границы

- Не публикует, не заходит в Instagram, не пишет в директ и комментарии.
- Стратегия, хук недели, медиаплан, разбор метрик — `/nika`. Презентации — Design Department. Сайты — `/taste`.
- Менять саму систему (`design-system/`) — только по решению Антона; правка = обновить DESIGN.md и эталон.
