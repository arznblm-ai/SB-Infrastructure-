# SB Infrastructure

Private repository for Anton's Second Brain infrastructure.

This repo is intended to version the reusable system layer:

- Codex / Second Brain skills
- research department operating docs, references, templates, and scripts
- automation scripts
- local app source code where safe
- architecture notes and workflow documentation

This repo intentionally excludes personal notes, meetings, transcripts, Codex sessions, raw research workspaces, exports, generated outputs, credentials, tokens, and local runtime folders.

## Safety Rules

- Keep the repository private by default.
- Do not commit `.env`, tokens, credentials, private meeting notes, transcripts, session logs, or raw research outputs.
- Prefer committing reusable instructions, templates, scripts, and source code.
- Run a secret scan before pushing.
